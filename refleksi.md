# Reflection

Using Git for this assignment was different from my usual way of saving files with names like final_revisi. One thing that felt easier was being able to keep track of changes in one place. I could see the history of my work and understand what I changed in each commit, instead of opening several files to find the latest version.

However, learning the commands was more difficult at first. I had to understand how to move into the correct folder, initialize the repository, and use commands such as `add`, `commit`, and `diff`. I also needed to pay attention to Markdown formatting so the notes would display correctly.

Overall, Git takes some practice, but it provides a more organized way to manage files and their changes. I would like to learn more about branching and merging, especially how several people can work on the same project without overwriting each other's work.
